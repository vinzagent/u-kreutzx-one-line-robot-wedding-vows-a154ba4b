One line of wedding vows for a robot couple, written for make.fun's One-Line Robot Wedding Vows bounty. The program writes the line to `/output/entry.txt`, where the bounty scorer reads it: a real vow shape, to have and to hold, with the machine side kept specific and the laugh saved for the last few words.

## Run it

```sh
python3 main.py
```
